# Sample Unity Project (Code Review Purpose)

This repository is created as a sample project for code review and evaluation purposes.

It is intended to demonstrate coding style, architecture design, and technical skills in Unity development. This is not a full production project, but a simplified example to showcase core systems and implementation approaches.

## Purpose
- Provide a clear overview of coding structure and practices
- Demonstrate experience in system design and architecture
- Showcase implementation of key features (e.g., ECS, multiplayer, performance optimization)

## Notes
- This is not a complete game project
- Focus is on code quality, structure, and technical approach
- Designed for initial technical evaluation and hiring review
